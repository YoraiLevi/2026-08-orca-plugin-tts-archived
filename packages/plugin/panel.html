Shortcuts need app focus. Click the sidebar or a settings pane first — with a terminal focused, ORCA does not deliver plugin shortcuts at all. For terminal-heavy work use huddle mode, which needs no shortcut once it is on.
Other limits. ORCA exposes no way for a plugin to read your editor selection, so the hotkey speaks the clipboard. Huddle mode reads agent transcripts and supports Claude, Codex, Grok and omp only. Audio plays from the plugin worker, so there is a short pause between sentences.
